# FoxScreenShots

## Visão Geral do Projeto

aplicativo cross-platform (windows, linux e mac) para auxiliar na captura e edição básica de screen shots

## Tech Stack

| Categoria | Tecnologia | Versão / Notas |
|----------|------------|-----------------|
| Front/back | flutter | latest |


## Funcionalidades Principais

- Tem dois modos de operação. O primário, no qual, quando o usuário o aciona, congela as telas e abre para o usuário fazer uma seleção da imagem que deve ser recortado
- O outro modo é o timer, que faz com que o usuário selecione a parte da tela antes, mas tira o screen shot depois de alguns segundos, podendo permitir que o usuário acione menus, tooltips, etc
- Deve ter barra de tarefas, com arquivo, configurações, etc
- Deve ser localizado em pt-br e en-us
- Deve ter UI bonita, com ícones agradáveis
- Use os mesmos esquemas de cor claro/escuro do app ~/development/mobile/foxdevelops

## Critérios de Aceite

- testes unitários
- testes e2e, se possível
- verificação de segurança do aplicativo a cada release
- Use boas práticas de desenvolvimento de código. código deve ser modular, reutilizável e bem organizado em arquivos e pastas
